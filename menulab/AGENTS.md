# menulab/

Workbench for other ways to do the main menu. `noindex`. It changes nothing on the menu.

- The live menu runs in a frame and shows twelve toys, with a Re-roll (key R). A roll never repeats a toy before the rest had a turn.
- Concepts on the switch (`index.html`): Dozen (default), Clock, Dial, Drum. Git history keeps the cut ones.
- Signal Intro menu workbench (`signal.html`): Dial main menu (dev layout switcher removed from chrome; `?m=<id>` still works if needed).
