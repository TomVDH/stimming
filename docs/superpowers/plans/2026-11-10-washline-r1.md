### Task 1: core.js physics, with node tests

**Files:**
- Create: `washline/core.js`
- Test: `tests/washline-core.test.mjs`

**Interfaces (Produces):**
- `K4`: `makeRope`, `stepRope`, `solveRope`, `makeCloth`, `stepCloth`, `solveCloth`, the same as in `archive/legacy.html`.
- `makeLine(a: [x,y,z], b: [x,y,z], { n = 64, slack = 1.015, mass = 0.04 }) -> line`, where `line = { rope, a, b, len, pieces: [] }`.
- `ropeAt(rope, s, out[3]) -> out`: the point at arc length `s`, interpolated between rope points.
- `makePiece({ w, h, col, cols = 18, rows = 14 }) -> piece` (a K4 cloth plus `pegs: [{ s, p }]`, `mass`, `col`).
- `hang(line, piece, s0)`: pegs at the two top corners, at `s0` and `s0 + w`.
- `reel(line, ds) -> applied`: shifts every peg's `s` by `ds`, clamped so that every peg stays in `[0.25, len - 0.25]`.
- `stepWorld(line, t, wind)`, with `wind = { u, turb, scale }`. It runs one 1/120 s step: wind on the cloth, loads into the rope, solve, and pegs pinned to `ropeAt`.
- `WIND = { calm, breeze, blowy }`, each `{ u, turb }`.

- [ ] **Step 1: Write the failing tests** in `tests/washline-core.test.mjs`, with `node:test`:
  - `ropeAt` at `s = 0` returns `line.a`; at `s = len` it returns `line.b`, within 1e-6.
  - On a 5 m line, after `hang` at 0.4 (w 1), `reel(line, 10)` returns less than 10. The last peg `s` is then ≤ `len - 0.25`. `reel(line, -10)` brings the first peg to ≥ 0.25.
  - Three pieces, 600 `stepWorld` calls in `WIND.blowy`: every cloth coordinate is finite. The rope's middle point sits below `a.y`.
  - After those steps, every pegged cloth point equals `ropeAt(s)` within 0.02, allowing for the peg offset.
- [ ] **Step 2:** Run `node --test tests/washline-core.test.mjs`. Expected: it fails, because the module is missing.
- [ ] **Step 3:** Write `core.js`. Lift K4 from `archive/legacy.html`. Wind is a steady direction plus a cheap sine-sum turbulence, with no imports. A peg's load splits between the two rope points that bracket its `s`.
- [ ] **Step 4:** Run the tests. Expected: all pass.

### Task 3: cloth.js, alley.js and index.html

**Files:** create `washline/cloth.js`, `washline/places/alley.js` and `washline/index.html`.

**Interfaces:**
- `cloth.js`: `makeLook(THREE, scene) -> { addPiece(piece, pal), removePiece(piece), sync(line, camera), setSun(dir, col, b) }`. Max, multiply and add passes, as in the legacy material. The line is a camera-facing ribbon. Pegs are instanced. Each pulley is a small wheel.
- `places/alley.js`: `export default { id: 'alley', name: 'Alley', anchors: { a, b }, sun: { dir, col }, sky: { zen, hor }, frame(camera, aspect), build(THREE, scene) }`.
- Alley set: two facades about 5 m apart, running 80 m down the street. Plaster colours vary per building. Windows have shutters and sills. A cobbled street, a far end of haze and a low sun at the end of the street. The line sits about 8 m up, between two windows. The camera is at street level, about 1.6 m, with a wide lens looking up the slot. Sun shadows come from a DirectionalLight shadow map.
- `index.html`: Bar v2 with `choice` (one segment, Alley), slider Sun, `quality: true` and Settings Wind (Calm, Breeze, Blowy). Three pieces start hung. The loop and idle sleep follow `archive/legacy.html`.
