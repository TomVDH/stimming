# Interchange trails (`interchange`)

Status: active · Bean: `stimming-hjsw` · Idea 373, group B.

Tom picked it on 2026-11-23, first of three traffic toys ("3 - 1 - 5"). It starts in the Lab.

## The idea

A motorway interchange at night, from straight above, as a long exposure. Headlight trails draw the flow. Swap the design and the trails rebuild; jams knot.

## Built

- [x] A network builder: a design gives the northbound ramps; four quarter turns give the rest.
- [x] Cloverleaf, turbine and stack.
- [x] The driver model on links, with merges where the lane has the right of way.
- [x] The plate: a float buffer that fades by blending; lamp strokes weighted by time per metre.
- [x] Inbound white, outbound red, from the camera over the crossing.
- [x] The still map: fields, decks in height order with shadows, paint, lamp pools.
- [x] A swap: the map cross-fades, the old trails fade fast.
- [x] Bar v3: Design, Clear, Traffic. Tap to brake, hold to stop.
- [x] Megastack: five deck levels, carpool flyovers, U-turn loops (Tom: "a multialyered LA-like or shenzen type situation").
