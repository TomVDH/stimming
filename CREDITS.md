# Credits

Every outside asset the site uses: models, textures, sounds, fonts, map data.
A new download needs Tom's yes first (file, source, size, licence), then a row here.
This file is the record; `credits/index.html` is the public page.
A new row here, or in a toy list below, also goes on that page in the same commit: what, by whom, licence, link, which toy.
The page also lists the code libraries in `docs/standards/code.md`; a new library goes there too.
