# introlab/

Workbench for the intro (`shared/intro.js`). `noindex`.

- `?v=<variety>` loads a variety. Signal ships; the others are proposals.
- Knobs: Layout, Type, Box, Glass, Timing. Timing stays locked to the variety's table until Tom unticks it.
- Static mode holds every line on screen. No knob moves the logo.
- Slow load shows the load line.
- A look takes no breathing or pulsing parts.
